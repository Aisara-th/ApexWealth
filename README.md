# ApexWealth Planner — ระบบวิเคราะห์แผนการเงิน พอร์ตประกัน และภาษี (Updated v3)

## รายการอัปเดตล่าสุด
1. **แถบเมนูด้านล่างไม่เลื่อนตามจอ (Static Bottom Dock)**: ย้ายแถบด้านล่างไปไว้ท้ายสุดของหน้าเว็บ ไม่ลอยบังเนื้อหาเวลาเลื่อนอ่านบน iPad/มือถือ
2. **ซ่อนปุ่มส่งออก/นำเข้า JSON สำหรับผู้ใช้ทั่วไป**: แสดงปุ่ม `ส่งออก JSON` และ `นำเข้า JSON` เฉพาะเมื่อล็อกอินด้วยบัญชีแอดมิน (`Admin132611`) เท่านั้น
3. **ยกระดับคุณภาพรายงาน PDF 5 หน้า A4 สำหรับ iPad & คอมพิวเตอร์**:
   - ยกเลิกกรอบจำลองหน้าจอ iPad อัตโนมัติขณะพิมพ์ (ไม่ให้มีเส้นดำซ้าย-ขวาติดมาใน PDF)
   - ปรับความคมชัดสีตัวอักษร หัวตาราง และป้ายสถานะให้แสดงผลคมชัดบน iPadOS Safari 100%
   - ป้องกันตัวเลขถูกตัดขึ้นบรรทัดใหม่ และจัดหน้ากระดาษให้พอดี 5 หน้า A4 พร้อมแผนผังสามเหลี่ยมการเงินแบบ Vector SVG
4. **ระบบสมัครสมาชิก & เข้าสู่ระบบแบบไม่ต้องใช้รหัสผ่าน (Passwordless) + เชื่อมต่อบัญชี Google**:
   - **สมัครสมาชิกใหม่**: กรอกเพียง ชื่อ-นามสกุล, เบอร์โทรศัพท์, อีเมล (หรือไอดี) และ LINE ID โดยไม่ต้องตั้งรหัสผ่าน
   - **เข้าสู่ระบบสมาชิก**: กรอกเพียง อีเมล, เบอร์โทรศัพท์ หรือชื่อที่ลงทะเบียนไว้ เข้าใช้งานได้ทันที (ส่วนแอดมิน `Admin132611` มีช่องรหัสผ่านป้องกันเหมือนเดิม)
   - **เชื่อมต่อบัญชี Google**: รองรับทั้งการคลิกเชื่อมต่อด้วยอีเมล Google ทันที และรองรับการใส่ Google OAuth Client ID ในหน้าตั้งค่าแอดมิน
