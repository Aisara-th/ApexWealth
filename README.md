# ApexWealth Planner

ระบบวิเคราะห์แผนการเงิน พอร์ตประกัน และวางแผนภาษีส่วนบุคคล

### วิธีเปิดใช้งานบน GitHub Pages:
1. อัปโหลดไฟล์ `index.html` ไปยัง Repository ของคุณบน GitHub
2. ไปที่ **Settings** -> **Pages**
3. ที่หัวข้อ **Build and deployment** ให้เลือก Branch เป็น `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1-2 นาที GitHub จะสร้างลิงก์เว็บไซต์ให้คุณใช้งานได้ทันที
